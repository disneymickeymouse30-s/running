# RUNNING TRAINING LOG

ランニング・ウォーキングの練習記録WEBアプリです。大会カウントダウン、練習記録、カレンダー、統計、目標管理、次回の練習提案、Apple Watch記録のファイルインポートができます。

- **外部APIは使いません。APIキーも不要です。**
- 記録や健康データを外部サーバーへ送信しません。処理と保存はすべてブラウザ内です。
- **Apple Watch・ヘルスケアとの自動同期には対応していません。**（ファイルを使った手動インポートのみ）
- **iPhoneとPCなど、端末間の自動同期には対応していません。**（バックアップ／復元で移せます）

## ファイル構成

| ファイル | 内容 |
|---|---|
| `running-training-log.html` | アプリ本体（HTML・CSS・JavaScriptをこの1ファイルに収録） |
| `sw.js` | オフライン起動用（任意）。HTMLと同じフォルダに置いて使います |
| `README.md` | このファイル |

## 起動方法

1. `running-training-log.html`（必要なら `sw.js` も）を、HTTPSで公開できる場所に置きます（GitHub Pages など）。
2. iPhoneのSafariでそのURLを開きます。
3. 共有ボタン →「ホーム画面に追加」で、アプリのように起動できます。

PCで試すだけなら、HTMLファイルをブラウザで直接開いても動きます（この場合オフライン起動は使えません）。ローカルサーバーで開く場合の例：`python3 -m http.server` → `http://localhost:8000/running-training-log.html`

### オフライン起動（任意）

`sw.js` をHTMLと同じフォルダに置き、アプリの「設定 → アプリについて → オフライン起動を使う」をオンにします。以後、一度開いたページがキャッシュされ、電波がなくても起動・閲覧・記録の入力ができます。`sw.js` を置いていない環境では、この設定はオフのままにしてください。

## 対応ブラウザ

- iPhone：Safari（iOS 16.4以降を推奨。ZIPのまま読み込む機能に必要）
- PC：Chrome / Edge / Safari / Firefox の最新版
- iOS 16.4より古い場合は、ZIPを「ファイル」Appで展開して `export.xml` を選んでください。

## データ保存方式

- ブラウザ内データベース（IndexedDB）に保存します。再読み込みやブラウザを閉じても残ります。
- 保存先は端末・ブラウザごとに別です。Safariとホーム画面のアプリで別になる場合もあります。
- ブラウザの「履歴とWebサイトデータを消去」、アプリの削除、容量不足時のブラウザによる削除で記録が消えることがあります。

## バックアップ方法

- **設定 → JSONバックアップ**：全データ（練習記録・大会・目標・予定・設定・シューズ・インポート元情報）を1ファイルに書き出します。
- **設定 → データ復元**：バックアップを読み込みます。件数をプレビューしてから「置き換え」か「追加」を選べます。失敗した場合、既存データは変更されません。
- **設定 → CSV出力**：練習履歴を表計算ソフト用に書き出します（BOM付きUTF-8で文字化けしにくい形式）。
- ホーム画面アプリでは、書き出し時に共有シートが開きます。「ファイルに保存」を選んでください。

## Appleヘルスケアからのファイル書き出し手順

1. iPhoneの「ヘルスケア」Appを開く
2. プロフィール（右上のアイコン）から、「すべてのヘルスケアデータを書き出す」などのデータ書き出し項目を探す
3. 書き出したファイル（export.zip）を「ファイル」Appなど、あとで選べる場所に保存する
4. このアプリのインポート画面（ホーム下部、または 設定 → Apple Watchデータのインポート）を開く
5. 書き出したファイルを選ぶ（ZIPのままでも、展開した `export.xml` でも可）
6. プレビューで記録内容と重複の警告を確認する
7. 取り込む記録を選んでインポートする

iOSのバージョンによってメニュー名や場所は異なります。書き出しには数分かかり、ファイルが数百MB以上になることもあります。

## 対応するファイル形式

### AppleヘルスケアXML（上限3GB）
`export.zip` または `export.xml`。ファイル全体を一度に読み込まず、少しずつ読みながら `<Workout>` 要素だけを取り出します。
- 読み取る項目：ワークアウト種別、開始・終了日時、運動時間、距離と単位、平均・最大心拍数、消費エネルギー、記録元
- 旧形式（`totalDistance` 属性）と iOS 16以降の形式（`WorkoutStatistics` 子要素）の両方に対応
- 平均・最大心拍数は、ファイルに集計値（WorkoutStatistics）がある場合のみ使います。個別の心拍データから平均を計算することはしません
- マイル・メートル等はkmに変換します。判別できない単位は変換せず空欄にし、警告を表示します
- DTD・外部実体参照は解析しません（実体参照を含む記録はエラーとして拒否）

### CSV（上限10MB、UTF-8）
1行目の列名（順不同、不要な列は省略可）：

```
実施日,開始時刻,練習種別,距離(km),運動時間,平均ペース(分/km),平均心拍数,最大心拍数,疲労度,メモ,データ取得元
```
- 必須：`実施日`・`練習種別`、および `距離(km)` か `運動時間` のどちらか
- 実施日：`2026-10-01` または `2026/10/01`、運動時間：`1:05:30` または `32:10`
- 上記以外の列名があるとエラーになります。このアプリのCSV出力はそのまま読み込めます（`平均ペース`・`データ取得元` は読み込み時に使いません）

### JSON（上限10MB）
```json
{"format":"rtl-workouts","version":1,"workouts":[
 {"id":"任意の識別子","date":"2026-10-01","startTime":"06:30","type":"ジョギング",
  "distanceKm":5.2,"durationSec":1860,"avgHr":148,"maxHr":165,"fatigue":2,"memo":""}]}
```
`date`・`type` と、`distanceKm` か `durationSec` のどちらかが必須。上記以外の項目があるとその記録はエラーになります。

## ファイルインポートの手順と重複の扱い

1. ファイルを選ぶと、進行状況を表示しながら読み込みます
2. プレビューで、取り込む種類（ランニング・ウォーキング等）と記録する練習種別を選びます。初期状態ではランニングとウォーキングのみ選択されます
3. 各記録は「新規」「取込済み」「重複の可能性あり」「取込不可」に分類されます
   - 取込済み：記録元＋開始日時＋終了日時が一致（ヘルスケアの書き出しにはワークアウト固有IDがないため、この組み合わせで照合）
   - 重複の可能性あり：同じ日で、距離・時間が近く、開始時刻の差が10分以内（または時刻が不明）の既存記録がある。ファイル内でiPhoneとApple Watchの記録の時間帯が重なる場合も該当。初期状態では選択されず、判断はユーザーに任せます
   - 同じ日の別の時間帯の練習は、重複とみなしません
4. インポートは1回の処理で一括保存し、途中で失敗した場合は何も追加されません。既存の記録は上書きしません
5. 結果画面で、追加件数と「追加前＋追加分＝追加後」の集計確認を表示します

### 計算・集計のルール
- 平均ペース＝運動時間÷距離、平均速度＝距離÷運動時間。距離か時間が0・未入力なら計算しません
- 表示の丸め：距離は小数2桁、ペースは秒単位、速度は小数1桁、割合は整数
- 距離のない記録は走行距離に加算せず、回数と時間には反映します。予定や休養日は集計しません
- 週は月曜始まり。目標の達成率は過去の期間も現在の目標値で計算します
- 目標タイムからのペースは「目標タイム÷種目の距離」の理論値で、走力や完走可能性を示すものではありません
- 練習提案は記録にもとづくルール（痛み、疲労度、距離の急増、大会までの日数、練習頻度）で、医療的な診断ではありません

## 既知の制約・未実装

- Apple Watch／ヘルスケアからのリアルタイム取得・自動同期（HealthKit）は未実装。HealthKitはネイティブアプリ専用のため、将来はiPhoneネイティブアプリの別プロジェクトとして設計する想定です
- 端末間の自動同期・クラウド保存はありません
- ワークアウトのGPSルート（workout-routes）、区間・ラップ、個別の心拍データは取り込みません
- ヘルスケアのワークアウト固有IDがないため、重複判定は日時・記録元・距離・時間による照合です。記録元の名前を変更した場合などは「取込済み」と判定できないことがあり、その場合は「重複の可能性あり」で表示されます
- 練習種別の名前を変更しても、過去の記録の種別名は変わりません
- 大会の結果タイムを入力する専用欄はありません（メモに記入）
- 数字用フォント（Barlow Condensed）はGoogle Fontsから読み込みます。オフライン時や読み込めない場合は端末のフォントで表示されます
- PWAのインストール・ファイル選択・オフライン動作はiOSとブラウザの仕様に依存します。実機での確認をおすすめします
